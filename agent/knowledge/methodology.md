# 공감형 숏폼 대본 공식 (두유노홈디노 분석 기반)

> `index (1).html`의 분석 리포트에서 추출한 방법론.
> 대본 생성 단계(script 툴)의 시스템 프롬프트에 이 내용을 주입한다.

## 핵심 한 줄
제품을 팔려고 하지 않고 **공감을 먼저 산다.**

## 잘 나오는 패턴 (목표)
- 공감형 (95점): "패딩 벗어서 바닥에 두는거 나만 그런 줄 알았는데.." → 21만
- 문제해결형 (92점): "이거 하나 있으면 겨울에도 운동걱정없겠네!" → 67만
- 감탄형 (88점): "손 뻗으면 바로 냉장고가 있다는게.. 이렇게 설렐일인가요" → 11만
- 정보전달형 (85점): "인테리어하는 친구가 알려준 요즘 대세 바닥 몰딩" → 11만

## 안 나오는 패턴 (피할 것)
- 과장형 (25점): "우리집이 갑자기 호텔로 바뀌는 마성의 조명 화장대"
- 명령형 (22점): "이제 비누도 디스펜서 시대!! 꼭 바꾸세요"
- 홍보형 (18점): "이거 요즘 엄청 핫한데 자취생들 적극 추천 1위 소파!!"
- 전문가형 (15점): "인체공학적으로 척추를 바르게 받쳐주니 세상 편안한 의사 추천"

## 기승전결 구조 (60초)
- 起 (0-5초) 문제 제시: "패딩 벗으면 어디 두지?" → "어? 나도 그래"
- 承 (5-15초) 공감 형성: "다들 바닥에 두잖아요" → "맞아 맞아"
- 轉 (15-50초) 솔루션 제시: "이 행거 하나로 해결" → "오 괜찮네?"
- 結 (50-60초) 만족감: "현관이 깔끔해졌어요" → "나도 사야지"

## 제목/첫 문장 체크리스트 (8가지)
1. 제품명이 아닌 "문제"가 먼저 나오는가?
2. "나만 그런가?" 공감 유발 요소가 있는가?
3. "핫한/추천/1위" 같은 홍보 언어가 없는가?
4. "호텔로 바뀌는" 같은 과장 표현이 없는가?
5. "꼭 하세요" 같은 명령형이 없는가?
6. 전문 용어 대신 일상 언어를 사용했는가?
7. 제목만 봐도 무슨 고민인지 이해되는가?
8. 솔루션을 직접 말하지 않고 호기심을 유발하는가?

## Before → After 변환 예시
- "이거 요즘 엄청 핫한데 자취생들 적극 추천 1위 소파!!" (1.1만)
  → "소파 살 돈 없어서 바닥에 앉았는데... 이거 발견하고 인생 바뀜" (20만+)
- "우리집이 갑자기 호텔로 바뀌는 마성의 조명 화장대" (4.1만)
  → "화장대 조명 때문에 매번 화장 망쳤는데 이거 하나로 해결" (30만+)
- "이제 비누도 디스펜서 시대!! 꼭 바꾸세요" (3만)
  → "미끌미끌한 비누 떨어뜨려서 짜증났던 사람? 이거 써보세요" (40만+)

## TTS용 추가 규칙
- 혀가 길어지는(군더더기) 문장은 쳐낸다. 짧고 말하기 쉬운 구어체로.
- 한 문장은 너무 길지 않게. 자막 한 줄에 들어갈 호흡으로 끊는다.
- 광고 티 나는 단어 금지. 친구한테 말하듯.
